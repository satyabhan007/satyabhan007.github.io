LoRA & QLoRA: Low-Rank Adaptation Mechanics
Source: Avi Chawla (MastercardAI) • Track: AI Engineer • Difficulty: Hard
▼
The Mathematical Decomposition:

Base frozen weights W_0 ∈ R^{d × k} are preserved. The update ΔW is factorized into B ∈ R^{d × r} and A ∈ R^{r × k} where rank r ≪ min(d, k):

h = W_0 * x + (alpha / r) * (B * A) * x
  • Matrix A: Initialized with Gaussian random values ∼ N(0, σ²).
  • Matrix B: Initialized to zero, ensuring ΔW = 0 at training onset.
  • QLoRA Innovation: Base model is quantized to 4-bit NormalFloat4 (NF4) with Double Quantization, enabling a 70B parameter model to be fine-tuned on a single 48GB GPU!
