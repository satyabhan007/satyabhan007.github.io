The Hardware Boundary Rule:
  • Tensor Parallelism (TP=8): Must stay intra-node over NVLink (900 GB/s). TP splits matrix operations layer-by-layer, requiring massive high-frequency All-Reduce synchronizations. Running TP over Ethernet or standard InfiniBand will crater performance.
  • Pipeline Parallelism (PP=8): Runs inter-node over InfiniBand. Layers are partitioned sequentially across nodes; only activation tensors flow between pipeline stages.
  • Data Parallelism (DP=4): Replicates 3D grids across the cluster with ZeRO-3 / FSDP gradient reductions.
