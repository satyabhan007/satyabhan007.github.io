QA-03 • LangGraph Core
LangGraph Checkpointer Crash & Duplicate Payment Bug
Source: Naved Khan (LangGraph Core) • Track: AI Engineer • Difficulty: Hard
▼
The Bug: An autonomous agent calls Stripe to charge $150. Mid-node network drops. Checkpointer rolls back to beginning of node. Customer is charged twice.
The Solution:
  • Never generate idempotency tokens inside the mutation node!
  • State nodes must be pure. Generate the token in an upstream planning node and store it in state["idempotency_key"].
  • On checkpointer replay, the external API recognizes the identical token and returns the original transaction.

Model Context Protocol (MCP) vs Traditional REST APIs
Source: Pavan Belagatti & Rohit Ghumare • Track: AI Engineer • Difficulty: Medium-Hard
▼
  • Dynamic Discovery: MCP clients query tool capabilities over JSON-RPC on demand, eliminating 15,000 prompt tokens of static Swagger schemas.
