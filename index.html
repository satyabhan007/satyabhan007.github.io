An LLM-powered CRM that handles patient communication and appointment workflows over WhatsApp for multiple clinics. Combines the WhatsApp Business API with the Gemini LLM and a Qdrant-backed RAG pipeline for clinic-specific knowledge, using Firestore for data and Redis (Upstash) for caching — deployed on Firebase Hosting with GitHub Actions CI/CD. Currently in pilot testing with two clinics on free trial.

  • Owned architecture, backend integration, deployment, and iteration end to end, solo.
  • Integrated the WhatsApp Business API with the Gemini LLM for conversational automation.
  • Built a RAG pipeline using Qdrant as the vector database for clinic-specific FAQ and knowledge handling.
  • Used Firestore (NoSQL) for application data and Redis (Upstash) for caching and session state.
  • Deployed on Firebase Hosting with GitHub Actions CI/CD and Git/GitHub for version control.
