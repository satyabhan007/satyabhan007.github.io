An LLM-powered conversational CRM handling patient communication and appointment workflows over WhatsApp for multiple clinics. It pairs the WhatsApp Business API with the Google Gemini LLM and a Qdrant-backed hybrid RAG pipeline for clinic-specific knowledge. The service runs on GCP Cloud Run behind an Express / Node.js backend, with Firestore NoSQL and two-tier Redis caching. Delivery is Firebase Hosting with GitHub Actions CI/CD. Currently in pilot testing with two clinics.

  • End-to-end autonomous agent: multi-turn patient scheduling, clinic FAQs and autonomous booking with 2-way Google Calendar OAuth sync.
  • Full-stack architecture: React 18 + TypeScript + Vite frontend, Express / Node.js backend on GCP Cloud Run, Firestore NoSQL, Turborepo monorepo. Verified by 860+ automated tests (Vitest unit + Cypress E2E + k6 load), with BigQuery & Looker Studio analytics per clinic.
  • High-throughput RAG: hybrid Qdrant vector retrieval with two-tier Redis caching, targeting sub-2-second response latency. Semantic intent routing separates deterministic transactional actions from generative queries, cutting average LLM token consumption by ~40%.
  • Production reliability: multi-tier AI resiliency (Gemini Flash → Flash-Lite → template fallback) and clinical guardrails with human handoff escalation. DPDP Act consent and PII redaction are enforced, and CI/CD runs on GitHub Actions with Workload Identity Federation — zero service-account keys.
  • Scale target: 1,000 clinics × 100 patients/day. Owned architecture, backend integration, deployment and iteration solo.
