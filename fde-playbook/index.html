Q1. Agent vs Reliable Agent

Full interview question: Candidate builds LangGraph agent. What if tool returns unexpected response? Does workflow recover? Are retries/timeouts handled?
30-sec answer to say: Timeout 10s, retry 3x exponential, Pydantic validate, fallback to cache/human, checkpoint resume, trace in LangSmith.

Learn: SUV model

Demo = glass car. Reliable = SUV: seatbelt=timeout, airbag=retry, reroute=fallback, dashcam=tracing, save-game=checkpoint.

Q2. RAG vs Evaluated RAG

Full question: Many connect docs to vector DB. How measure retrieval quality? Without eval you rely on few queries and hope prod works.
30-sec answer: Golden 200 QA set, retrieval metrics (Recall@k, MRR) + generation (Faithfulness) separately via RAGAS + Phoenix, CI gate ship only if faithfulness over 0.85.

Learn: Librarian + Writer

Librarian=find pages. Writer=answer only from pages. Test separately. Wrong book vs invented story.

Q3. Tools vs Orchestrated Workflows

Full question: Agent retrieves customer, calls API, validates, updates system. What if API fails halfway? Needs state, validation, recovery, control.
30-sec answer: State machine with validation each step, saga compensation (refund if later fails), idempotency, human approval for risky actions, resume.

Learn: Conductor + Saga

Tools=musicians, conductor=state score. If hotel fails after flight booked, cancel flight (compensate), not strand traveler.

get_customer -> charge -> reserve -> update_CRM -> Done | If reserve fails after charge: refund -> notify -> Done (no stuck money)

Q4. Building AI vs Solving Customer + 6 Skills

Full question: FDE must understand workflow, find real problem, work with existing APIs, tradeoff, deliver usable. Must learn: Execution, Evaluation, Orchestration, Debugging, Production, Customer solving.
30-sec answer: Shadow users, measure hours lost, wrap SAP/Salesforce (no rip-replace), ship slice in 2 weeks, cheap bulk + smart edge + cache, measure ROI dollars, add monitoring/security.
