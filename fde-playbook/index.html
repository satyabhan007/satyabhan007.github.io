Q1. Agent vs reliable agent

Interviewer asks: Refund tool returns {amount:null}. Does workflow recover? Retries/timeouts? Walk me through.
Tests: survive 3am prod, not demo.
Priya story: Demo froze on Stripe 500. No answer. That night she learned 5 shields. Next time she drew diagram below and got hired.
30-sec answer (say aloud): 10s timeout, 3 retries 2/4/8s, Pydantic validate, fallback cache/human, checkpoint resume, LangSmith trace.

Picture: without vs with (study 30s)

Before: No timeout hangs. Null crashes math. One 500 kills order. Restart double-charges. No trace = cannot explain.
After: Timeout stops hang. Pydantic rejects bad shape. Retries absorb flakes. Cache keeps user going. Checkpoint resumes. Trace proves Try1 fail to Try3 win.

Step-by-step: fix in this order (why each)

1
Timeout 10s: stops infinite hang. Ask: if API never replies, what saves you? Timeout.
2
Validate (Pydantic): Customer(balance:float) rejects null immediately, before bad math spreads.
3
Retry 3x: only for network/5xx/429 (transient). Never retry validation errors.
4
Fallback: cached balance or human. User sees help, not crash.
5
Checkpoint+trace: save progress, resume; record attempts to prove recovery.
READ CODE LINE BY LINE:
@retry(...) = auto retry flakes, wait longer each time
timeout=10 = never hang over 10s
Customer(**json) = reject wrong shape now
# checkpointer = save + resume after crash
from tenacity import retry, stop_after_attempt, wait_exponential
from pydantic import BaseModel
class Customer(BaseModel): id: str; balance: float
@retry(stop=stop_after_attempt(3), wait=wait_exponential(2,2,10))
def get_customer(cid: str):
 import requests
 r = requests.get("https://api.example.com/c/"+cid, timeout=10)
 r.raise_for_status()
 return Customer(**r.json())

Q5. Python for FDEs: async, timeouts, idempotent retries

Asks: Your agent calls 3 APIs. Sync code takes 9s. How make it 3s? What if one hangs? Show retry + idempotency.
Priya story: Her sync agent called CRM (3s) + billing (3s) + inventory (3s) = 9s. User left. She learned asyncio.gather + timeout + idempotency key. Now 3s, no double-charge on retry.
30-sec answer: asyncio.gather with per-call timeout, tenacity retry only idempotent ops with idempotency-key header, semaphore limits concurrency, structured logging with request id.

Picture: sync vs async timeline

READ: gather runs 3 at once. semaphore(5) caps load. timeout stops hang.
idempotency key lets you retry charge safely (server ignores duplicate).
import asyncio, uuid
from tenacity import retry, stop_after_attempt, wait_exponential
async def fetch_one(client, url, key):
    import aiohttp
    async with aiohttp.ClientSession(timeout=aiohttp.ClientTimeout(total=10)) as s:
        async with s.get(url, headers={"Idempotency-Key": key}) as r:
            r.raise_for_status(); return await r.json()
@retry(stop=stop_after_attempt(3), wait=wait_exponential(2,2,10))
async def safe_charge(url, payload):
    key = str(uuid.uuid4())  # same key across retries = no double charge
    return await fetch_one(None, url, key)
# results = await asyncio.gather(fetch_crm(), fetch_bill(), fetch_stock())

Q6. LangGraph deep: state, nodes, edges, checkpointing, human-in-loop

Asks: Draw your LangGraph: what is state? When use conditional edge vs tool node? How resume after crash? Where human approves?
Priya story: She drew boxes with no arrows. Interviewer: "Where does state live? What if node 2 fails?" She rebuilt: TypedDict state flows through every node, router edge picks next, checkpointer saves after each node, interrupt pauses for approval.
30-sec answer: TypedDict state is single source of truth. Nodes mutate it. Conditional edges route (success vs needs_fix vs escalate). Sqlite/Postgres checkpointer persists per thread_id. interrupt() pauses for human approve/reject. Time-travel replays from any checkpoint.

Picture: graph anatomy (memorize + redraw)

READ: state dict flows everywhere. router returns next node name.
interrupt pauses for human. thread_id = customer session. checkpointer = save-game.
from typing import TypedDict
from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver
class S(TypedDict): customer: dict; pay: dict|None; error: str|None
def fetch(s:S): return {"customer": {"id":"c1"}}
def router(s:S): return "charge" if s["customer"] else END
g=StateGraph(S); g.add_node("fetch",fetch); g.add_node("charge",lambda s:{"pay":{}})
g.set_entry_point("fetch"); g.add_conditional_edges("fetch",router)
app=g.compile(checkpointer=MemorySaver(), interrupt_before=["charge"])
# app.invoke({"customer":{}}, config={"configurable":{"thread_id":"cust-1"}})

Q7. Langfuse (you wrote langfse): observability, tracing, eval + cost

Asks: Prod agent hallucinates once in 50 calls. How find which step? How much does each trace cost? How score quality nightly?
Priya story: CEO: "Why did bot offer 50% discount?" No logs. She added Langfuse: every LLM call + tool + retrieval chunk traced with tokens, cost, latency. Next incident she opened the trace: retriever brought old promo PDF. Fixed in 10 min.
30-sec answer: Wrap LLM/tools with Langfuse observe decorators, log retrieval context + prompt + completion + tokens/cost/latency per span, run nightly eval dataset scoring faithfulness, alert on drift + cost spike, mask PII before send.

Picture: trace waterfall (what you open at 3am)

READ: @observe wraps functions. update_current_trace tags user/session.
Scores attach to trace. Mask PII. Self-host if needed.
from langfuse import observe, get_client
lf = get_client()
@observe(name="rag-answer")
def answer(q, ctx):
    lf.update_current_trace(user_id="cust-1", tags=["prod","refund"])
    out = llm(q, ctx)  # auto captures tokens/cost/latency
    lf.score_current_trace(name="faithfulness", value=0.94)
    return out
# nightly: run golden set, dataset_run, alert if avg drops or cost spikes

Q8. Advanced RAG: chunking, hybrid search, rerank, citations, freshness

Asks: Recall stuck at 0.68. Answers lack citations. Old price list still served. Fix retrieval step by step?
Priya story: 800-token chunks split fee tables in half. Dense search missed exact SKU "XJ-200". No rerank, no citations, 2022 price served in 2025. She fixed 5 layers: chunk - hybrid - rerank - cite - expire.
30-sec answer: Semantic chunks 400 with 15% overlap preserving tables, hybrid dense+BM25, cross-encoder rerank top-30 to top-5, force inline citations + refuse if unsupported, metadata date filter + nightly re-embed on doc change.

READ: split smart, search both ways, re-rank, force cite, expire old.
